# 🛍️ Next Store

A modern full-stack e-commerce application built with **Next.js 14**, **TypeScript**, **Prisma**, **Clerk Authentication**, **Stripe**, and **Supabase**. The application provides a fast, responsive shopping experience with secure authentication, online payments, and an intuitive user interface.

## ✨ Features

- 🔐 Authentication with Clerk
- 🛒 Browse products
- ❤️ Wishlist/Favorites
- 🔍 Product search
- 🌙 Light & Dark mode
- 💳 Secure Stripe Checkout
- ☁️ Image storage with Supabase
- 📱 Fully responsive design
- ⚡ Server Actions
- 🗄️ PostgreSQL database with Prisma ORM
- 🎨 Modern UI built with Radix UI and Tailwind CSS
